Original Windows printing setup (fallback)
  • Plug the TP870 into the computer with USB and install the Grozziie / TP870 Windows driver.
  • In Windows Printers & scanners → TP870 → Printing preferences, set the paper size to your label size (for example 100 × 150 mm) and make it the default printer.
  • Print opens the browser print dialog. Choose the TP870, set Margins: None and Scale: 100%.
  • For the kiosk, start Chrome with the --kiosk-printing flag so it prints straight to the default printer without the dialog.
